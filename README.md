# hexbridgemedia.co.uk

The one page every Hex Bridge Media QR code points at (books, colouring books, videos).

- Edit the lists in `build_site.py` (set a book's status to "out" once it's live on Amazon), then run `python3 build_site.py`, commit and push.
- Hosted on GitHub Pages; the domain is in `CNAME`.
- Never change the domain: it's printed in the books.
